# Sandbox

`ContainerSandbox` implements the architecture's `Sandbox.start` port. It drives an installed Docker-compatible CLI; it never starts a VM or installs a runtime. Supply `cli: ["podman"]` or CLI global options as needed. The driver builds its small relay image from `relay/` once per driver instance. Harness images need `/bin/sh`, `sleep`, `head`, `base64`, and libfaketime; probes also use `timeout`. `images/Dockerfile` is a minimal Node image with these tools and the library at the default path. Other images can set `faketimeLibrary`.

The relay runs with `--network none`; each workload joins only that network namespace. All capabilities are dropped from the workload, privilege escalation is disabled, and no host socket or home directory is mounted automatically. Callers supply only fresh materialized working trees or explicitly allowed evidence, never recordings, a moment bundle, credentials, or agent/container sockets. Reserved system paths and whole-home/ancestor mounts are refused. `clockFile` is mounted read-only at `/phoenix-clock`; rewrite it in place with `writeClockFile` to re-anchor it without replacing the mounted inode.

The relay's private Unix socket is in its own mount namespace, invisible to the workload. The host engine reaches that socket through `docker exec`'s byte stream, so macOS does not need to share a host Unix socket across a VM filesystem. `EngineChannel` multiplexes byte streams over this one connection; async iteration yields each connection's original DNS destination and port. `connect(port)` opens a connection in the other direction to a workload loopback listener (for HTTP plugins). No port is published on the host.

DNS returns addresses within `127.0.0.0/8`, keeping a name-to-address map so destinations survive the relay. By default TCP ports 80, 443 and 8080 are relayed; `relayPorts` can name the listeners needed by a recipe. Raw addresses and unlisted ports fail locally. `rawAddressReporting` is always `false`: this driver does not install redirect rules. The engine must record that limitation and decide how to answer all received bytes. The relay contains no policy, model credential or vendor client.

`start` runs an optional recipe `clockProbe` before the harness, then inspects the entry binary and `clockBinaries` for an ELF interpreter. The returned process records `virtual`, `real` or `unknown`; static binaries are `real`. Missing, timed-out (10 host seconds) or undecodable probes are `unknown`, never a refusal. Supply the engine's current `virtualTime` at the call to `start` for comparison and `dontFakeMonotonic` for runtimes that need it. Startup time is included in the comparison. This is information only; it never changes a fidelity grade. `process.exited` is the candidate outcome; `process.interrupted` reports a relay, channel or container failure. Call `stop` to remove both containers. Nothing silently reconnects or retries a replay.
