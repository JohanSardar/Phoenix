# Store

`createCapture` writes private capture metadata once. `createTraceWriter` owns one stream, validates and queues events under a byte bound, writes every accepted byte and fsyncs each event. Its caller is the collector worker, never the tap. `append` returns `queued` or `dropped` without awaiting disk. `drain` resolves once every event queued so far is synced, and rejects if any was dropped by a write failure; a replay engine uses it to make each event durable before it answers. `close` drains, records close and syncs; it rejects if writing remains unavailable. Write errors drop/count pending events and retry on a fresh generation. Recovery gaps use a generation-scoped companion stream and name the affected stream in their inline body, so they never consume a tap's sequence number. `onError` receives only an error code.

`BlobStore` accepts **already secret-stripped** bytes. A spool records its event and each chunk's starting offset and monotonic arrival time. Await each `append` before the next. `finish` syncs and renames the body to its content hash, syncs the directory, and returns an event safe to enqueue. Keep the spool until the event is durable, then call `release`. A crash anywhere before that leaves recovery metadata. `get` verifies the digest.

`appendCoverage`, `appendNote`, `writeSnapshot` and `writeImport` write the other capture files. Task notes use `kind: task`, `task: <key>`, and `op: start | end`. Imports are published atomically and deduplicated by reader plus source digest.

`readCapture` returns a point-in-time view, including while a capture is open. `runs()` and `events({capture, task}, from?)` compute attribution without changing evidence. Own task keys win over model pairing, which wins over the sole open task; everything else stays in `unattributed`. A capture with no task rule or markers is one run with an empty task key. The reader accepts `modelToolUses` and `toolUseId` callbacks from the caller's wire decoding, keeping dialect knowledge out of store. `taskMarker` can decode another marker representation. All tap events remain in monotonic/stream/sequence order; wall-only imports are interleaved approximately. Diagnostics report torn final lines, sequence holes, drops, open generations, partial spools and incomplete snapshots. Interior malformed or schema-invalid lines throw `StoreCorruption` with locations, not payloads.

`writeMomentBundle` publishes a new draft revision containing the manifest, data, custom-check files and optionally `check.draft.yaml`. It never writes the final check, lock or ledger: those belong to approvals. `readMomentBundle` reads an approved bundle, validates its formats, rejects escaping/symlink paths, and verifies complete lock coverage and file hashes. `readApprovalsLedger` is read-only. `bundleApproval` requires a matching non-pass acceptance of the lock hash. These helpers do not execute checks, create approvals, pack archives or materialize harness trees.

The reviewer-proven regressions run from the repository root with `node --test tests/store-*.test.mjs`.
